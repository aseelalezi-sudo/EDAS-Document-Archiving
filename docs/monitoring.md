# المراقبة والتنبيهات — EDAS

## المكوّنات

- **Prometheus** يجمع `/api/v1/metrics` (يتطلب `Authorization: Bearer $METRICS_TOKEN` في الإنتاج).
- **Alertmanager** يستقبل قواعد `infra/monitoring/alerts.yml`.
- **Grafana** لوحات من مقاييس `edas_http_*` و`edas_process_*` و`edas_nodejs_*`.
- **Loki/سجلات مركزية** إن توفرت؛ السجلات تحمل `correlationId` ولا تحتوي محتوى المستندات أو الرموز.

## أهداف الخدمة (SLO)

| المؤشر            | الهدف                                       |
| ----------------- | ------------------------------------------- |
| التوفر            | 99.9% شهريًا                                |
| زمن الاستجابة p95 | أقل من ثانية لطلبات القراءة/الكتابة العادية |
| نسبة 5xx          | أقل من 2%                                   |
| جاهزية القاعدة    | 100% لمدة 5 دقائق قبل التنبيه               |

القواعد الحالية تغطي تعطل الـAPI، فشل readiness، نسبة 5xx، بطء p95، تراكم الطلبات، الذاكرة، وتأخر event loop. أضف تنبيهًا خارجيًا لآخر نسخة احتياطية ناجحة (انظر `docs/backup-restore.md`) لأن Prometheus لا يعرف حالة النسخ دون exporter.

## ربط `correlationId` بالتتبع

كل طلب يحمل `x-correlation-id` (يُعاد في الترويسة وفي غلاف الخطأ)، ويدعم الخادم W3C `traceparent`: يعيد `x-trace-id` و`traceparent` ويضع `traceId`/`spanId` في سجل JSON لكل طلب. هذا تمهيد متوافق مع OpenTelemetry وليس SDK كاملًا. لا تُسجّل:

- رموز الوصول أو الكوكيز أو `x-csrf-token`،
- عنوان بريد أو اسم مستخدم مع محتوى المستند،
- محتوى ملف أو نص مستخرج.

## حماية نقاط النهاية

- `/api/v1/metrics` مقيّد بـ`METRICS_TOKEN` في الإنتاج؛ بدّله دوريًا ولا تضعه في `VITE_*`.
- لا تنشر Prometheus/Grafana على الإنترنت العام دون مصادقة شبكية.
- احتفظ بالمقاييس 15–30 يومًا، والسجلات 30–90 يومًا حسب السياسة، وسجلات التدقيق حسب متطلبات الاحتفاظ.

## التنبيهات التشغيلية

- تنبيهات أمنية أو تشغيلية فقط؛ لا إشعارات لمحتوى المستخدم.
- كل تنبيه يحمل `severity` و`runbook` ورابط لوحة.
- اختبر قواعد Prometheus بـ`promtool check rules infra/monitoring/alerts.yml` قبل الدمج.

## القيود

- لا توجد في المستودع بنية Prometheus/Grafana/Loki كخدمات compose (الملفات فقط).
- OpenTelemetry غير مدمج بعد؛ الربط أعلاه خطة تنفيذ وليس ادعاءً بوجوده.
