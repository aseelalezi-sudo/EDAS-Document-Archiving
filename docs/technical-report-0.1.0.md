> **تاريخ الفحص:** 2026-11-21
> **النطاق:** الفرع `master` عند الوسم `v0.1.0` (`a122472`) — الواجهة (SPA)، الخادم (API)، الحزمة المشتركة (`@edas/shared`)، قاعدة البيانات (Prisma/PostgreSQL)، البنية التحتية (Docker/Keycloak/MinIO/Redis/Observability)، الاختبارات، وخطوط CI/CD.
> **المنهجية:** مراجعة الكود والمخططات والإعدادات + **تشغيل فعلي** لجميع بوابات الفحص، الاختبارات، التغطية، بناء الإنتاج، اختبار المتصفح (Playwright)، وفحص الحاويات الحية.

## 1. الخلاصة التنفيذية

**التقييم الهندسي العام: متقدّم (8.8/10) — خط أساس مصلَّب قبل الإنتاج (Pre-Production Baseline).**

المشروع يتجاوز بكثير مستوى النموذج الأولي: فصل معماري نظيف، مصدر حقيقة واحد للصلاحيات، مصادقة **BFF** بكوكيز `httpOnly`، سلسلة تدقيق Hash-Chained محمية بأقفال استشارية في PostgreSQL، وانضباط آلي غير معتاد (**0 `any`، 0 `TODO`، 0 تحذيرات Lint، 2,654 اختباراً آلياً**، تغطية **92.07%** للواجهة و**98.19%** للـ API).

**ما يحتاج انتباهاً فورياً (مؤكد بالتشغيل):**

1. **~~بوابة `npm audit` في CI للـ API ستفشل عند أول تشغيل~~ — مُعالَج (2026-11-21):** كانت 3 ثغرات عالية (`GHSA-7589-6fvf-x4pw` في `effect <= 3.22.0`) عبر `prisma@6.19.3 → @prisma/config@6.19.3 → effect@3.21.0`، و`npm audit fix` **لا يستطيع إصلاحها** (تحقق: `@prisma/config` يثبّت `effect` بإصدار دقيق، وحتى `@prisma/config@7.10.1` يثبّت `3.20.0`). أُصلحت بـ`overrides.effect = "^3.22.5"`؛ التدقيق الآن **0** في الحزمتين.
2. **عدم استقرار عابر في تغطية Vitest على Windows + Node 24:** انهيار عامل واحد برمز `0xC0000409` في **1 من 2** تشغيلات، ثم نجاح كامل. غير مُعاد إنتاجه بشكل حتمي.
3. **فجوات تشغيل Day-2 موثّقة لكن غير مغلقة:** مستقبِل Alertmanager فارغ (لا تسليم تنبيهات)، لا جدولة مدمجة للنسخ الاحتياطي، وS3 Versioning مفعّل محلياً فقط.

## 3. المعمارية

```text
SPA: React 19 + TS 5.9 + Vite 7 + Tailwind 4 (RTL-first) + HashRouter + lazy routes
        │  httpOnly cookie (edas_session) + X-CSRF-Token
        ▼
API (BFF): NestJS 11 + Express 5 + Prisma 6 + Passport OIDC/JWKS
        │  Helmet · Throttler · ValidationPipe(whitelist+forbid) · OTel · Prometheus
        ▼
PostgreSQL 16 · Keycloak 26 (OIDC+PKCE, Admin API) · MinIO (versioned) · Redis 7 (BullMQ, optional)
```

**وضعان للتشغيل:** متصل (عند ضبط `VITE_API_URL` / `VITE_OIDC_ISSUER` / `VITE_OIDC_CLIENT_ID`) ومحلي تجريبي (بدونها)، مع حارس بناء `VITE_REQUIRE_API=true` يمنع شحن الوضع التجريبي بالخطأ.

## 4. تفصيل الطبقات

### 4.1 `@edas/shared`

مصدر الحقيقة الوحيد للأدوار الستة، والأفعال الستة (`VIEW/CREATE/EDIT/DELETE/APPROVE/EXPORT`)، و`canManageAcl` (مدير نظام أو أرشيفي فقط). يُستهلك مباشرة في الواجهة وفي الـ API.

### 4.2 الـ API

- **`auth` / `users`:** Authorization Code + PKCE من الخادم، تشفير الجلسة بـ AES-256-GCM في `UserSession`، تجديد توكن قبل 30 ثانية من الانتهاء، CSRF مزدوج، ومزامنة Keycloak Admin API.
- **`access`:** تقاطع سقف الدور (مع `RolePolicy`) ∩ `Folder.scope` ∩ سلسلة ACL حتى أول `aclInherit=false`، `DENY` يفوز، فشل مغلق.
- **`files` / `preview`:** روابط S3 موقعة + `UploadIntent`، تحقق خادمي من SHA-256 وMagic Bytes، تذاكر تنزيل موقعة مع منع تكرار التدقيق عبر `DownloadTicketUse`، تحويل Office بـ LibreOffice وCAD بـ ODA، طابور Redis اختياري.
- **`audit`:** سلسلة SHA-256 مع `prevHash` و`detail` مطبَّع، `pg_advisory_lock` للكتابة، تحقق `verifyChain` يكشف الكسر/التفرع/الفجوات مع `baseline`.
- **`reports`:** claim ذرّي للجدولة عبر النسخ، تصدير CSV/Excel/PDF عربي RTL.

### 4.3 الواجهة

تقسيم حزم مدروس (PDF/Charts/DXF تُحمَّل عند الطلب)، دعم RTL أصيل، وصولية كاملة. المواضع الثلاثة الوحيدة لـ `dangerouslySetInnerHTML` (تظليل البحث) تمر جميعها عبر `escapeHtml` — **ليست ثغرة** (تحقق).

### 4.4 البنية التحتية والعمليات

صورة API متعددة المراحل على digest، مستخدم غير جذري، `npm ci` + `prune --omit=dev`. مكدس مراقبة كامل (Prometheus/Alertmanager/Loki/Promtail/Grafana/OTel/Jaeger) خلف profile. سكربتات نسخ احتياطي مع تحقق استعادة معزولة.

## 6. الملاحظات والمخاطر

> كل بند يبدأ بحالة التحقق: **[مؤكد]** أو **[غير مؤكد]**.

### أولوية عالية

**H1 — [مُعالَج] فشل بوابة `Audit production dependencies` للـ API**

- الدليل الأصلي: `npm audit --omit=dev --audit-level=high --prefix api` → 3 High (`GHSA-7589-6fvf-x4pw`, ReDoS، `effect <= 3.22.0`).
- السبب: `prisma` في `dependencies` (تحقق: `deps.prisma=^6.0.0`)، و`@prisma/config@6.19.3` يثبّت `effect: 3.21.0` بإصدار دقيق.
- تحقق إضافي: `npm audit fix --dry-run` لا يُصلح؛ وحتى `@prisma/config@7.10.1` يثبّت `effect: 3.20.0`.
- **المعالجة (2026-11-21):** `"effect": "^3.22.5"` في `api/package.json#overrides` وتحديث الـ lock. التحقق بعد الإصلاح: `npm audit --omit=dev --prefix api` = **0**، التدقيق الكامل = **0**، `effect` = 3.22.5، و`prisma generate/validate` + 84 ملفاً/1,213 اختباراً + typecheck/lint/build ناجحة.

**H2 — [غير مؤكد/عابر] انهيار عامل Vitest مع تغطية v8 على Windows + Node 24**

- الدليل: خروج عامل `reports-audit.test.tsx` برمز `3221226505` (`0xC0000409`) في تشغيل واحد، ونجاح كامل في التشغيل التالي دون تغيير.
- لا يوجد إعادة إنتاج حتمية؛ CI يعمل على Node 22/Ubuntu. يُعامل كمراقبة لا كإصلاح عاجل.

### أولوية متوسطة

**M1 — [مؤكد] تحميل كامل لقوائم تشغيلية عند الإقلاع** — `src/store-docs.tsx:318-330` يستدعي `loadAllPages` للسلة والاحتفاظ ودليل الموظفين (بلا `maxPages`)، بينما المستندات محدودة بصفحة واحدة.
**M2 — [مُعالَج] `verifyChain` يقرأ السلسلة كاملة في الذاكرة** — كان `loadChain()` يستخدم `findMany` بلا `take`/cursor. **المعالجة (2026-11-21):** قراءة متدفقة بدفعات 1000 عبر cursor على `seq`، مع الحفاظ على نفس دلالات الكشف، واختباران جديدان (سلسلة 1001 حدث + تلاعب في الدفعة الثانية).
**M3 — [مؤكد] Alertmanager بلا وجهة تسليم** — `infra/monitoring/alertmanager.yml` يحتوي `receivers: - name: default` بلا أي نوع (webhook/slack/email)، فالتنبيهات تُبتلع.
**M4 — [مؤكد] لا جدولة نسخ احتياطي مدمجة + S3 Versioning إنتاجي غير مؤتمت** — موثّق صراحةً في `README.md:641` و`docs/backup-restore.md:55`.
**M5 — [مؤكد] انحراف توثيق CI عن الواقع** — `README.md` يقول إن `npm audit --audit-level=high` (كامل) هو البوابة، بينما CI الآن `--omit=dev` مع خطوة استشارية غير معيقة.

### أولوية منخفضة

**L1 — [مُعالج] مجلد فارغ غير متتبع** — حُذف `infra/monitoring;M` (كان 0 بايت وغير متتبع). مجلدا `api;C` و`.tmp-metrics-token;C` لم يكونا موجودين أصلاً.
**L2 — [مؤكد] مساعد `L(ar,en)` في 39 ملفاً** بالتوازي مع `src/i18n.ts`؛ يعمل لكن يعطّل الفحص الآلي لمفاتيح الترجمة.
**L3 — [مؤكد] ملفات كبيرة** — `store-docs.tsx` 1,930 سطراً، `data.ts` 1,478، `documents-library.tsx` 1,133، `reports.service.ts` 903.
**L4 — [جزئي] تحذيرات تهيئة مستقبلية** — ✅ أُعيدت تسمية `api/vitest.config.ts` إلى `.mts` (اختفى تحذير ESM/CommonJS). يبقى `package.json#prisma` المخطط لإلغائه في Prisma 7 (ترحيل إلى `prisma.config.ts` مؤجل حتى الترقية).

### ادعاءات فُحصت ولم تثبت

- **XSS عبر `dangerouslySetInnerHTML`:** 3 مواضع فقط، جميعها تمر عبر `escapeHtml` + CSP صارم → لا ثغرة.
- **`localStorage` للتوكينات:** لم يبق أثر؛ الجلسة بكوكي `httpOnly` فقط.
- **`any` / `@ts-ignore` / `eslint-disable`:** صفر في الكود غير الاختباري.
- **تسريب أسرار:** فحص الأسرار نظيف، و`.env` غير متتبع.
