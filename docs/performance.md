# اختبار سعة الوثائق

يشغّل **Document load benchmark** على GitHub Actions نسخة معزولة من PostgreSQL وMinIO وKeycloak وواجهة EDAS API. يمكن تشغيله يدويًا من تبويب Actions وتحديد عدد الطلبات المتزامنة. الإعداد الافتراضي مليون سجل وثيقة، موزعة على 16 قسمًا و256 مجلدًا، مع وثائق محذوفة وقواعد صلاحيات مختلفة.

يقيس السيناريو القائمة بحساب المدير والموظف، وصفحة قريبة من نهاية النتائج، والبحث العربي بحساب مقيّد، والتنزيل والمعاينة، ومسار الرفع حتى تسجيل الوثيقة. يسجّل التقرير عدد المحاولات والأخطاء وزمن الاستجابة للمئين 95 لكل عملية، وأقصى ذاكرة مقيمة لعملية API ومواصفات المشغّل. تبقى حدود زمن الاستجابة قرارًا مبنيًا على بيئة النشر وحملها المتوقع.

تستخدم سجلات الوثائق المزروعة ملف PDF مشتركًا، فيما ينشئ حمل الرفع كائنات MinIO مستقلة. يقيس هذا الإعداد أثر مليون سجل وإصدار على PostgreSQL ومسارات API مع عمليات تخزين فعلية. قياس سعة MinIO لعدد مماثل من الكائنات، والملفات الكبيرة، وتشغيل الحمل لساعات يتطلب بيانات ومدة اختبار تناسب الإنتاج.
